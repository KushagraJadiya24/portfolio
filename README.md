# Kushagra Jadiya Portfolio

Production-oriented Next.js portfolio for Kushagra Jadiya.

## Stack

- Next.js 16
- React 19.2
- TypeScript
- Tailwind CSS 4
- Motion
- Three.js / React Three Fiber

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```

## Notes

- Resume: `public/resume/Kushagra-Jadiya-Resume.pdf`
- Main editable content: `lib/data.ts`
- Theme preference is stored locally.
- The hero 3D object is intentionally lightweight and lazy-loaded.
- Project links are only included where a real link is available.
